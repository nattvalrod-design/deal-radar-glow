# Deal Flow Pro

Crea una aplicación web para seguimiento de ofertas comerciales. Debe permitir registrar Opportunity ID, nombre de oportunidad, cliente, responsable, estado, fecha de cierre y valor estimado. Incluir dashboard con indicadores, alertas de vencimiento, filtros, actividades pendientes y semáforo de seguimiento. Diseño moderno tipo Power BI/CRM. Preparar estructura para futura integración con IA.
